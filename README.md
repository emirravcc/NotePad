# 📝 C# Notepad Clone (Gelişmiş Not Defteri)

Bu proje, Windows'un klasik Not Defteri uygulamasının C# ve Windows Forms kullanılarak geliştirilmiş bir klonudur. Proje kapsamında dosya yönetimi, metin düzenleme ve sistem diyalog pencereleriyle çalışma pratikleri yapılmıştır.

## 🚀 Proje Özellikleri
* **Dosya İşlemleri:** Yeni dosya oluşturma, mevcut dosyayı açma, kaydetme ve "Farklı Kaydet" özellikleri.
* **Metin Düzenleme:** Kes, Kopyala, Yapıştır, Geri Al (Undo) ve Tümünü Seç işlemleri.
* **Özelleştirme:** Yazı tipi (Font) seçimi ve yazı boyutu ayarlama.
* **Kelime Kaydırma:** Word Wrap özelliği ile metinlerin ekran genişliğine göre hizalanması.
* **Durum Çubuğu:** Satır ve sütun takibi (isteğe bağlı özellik).

## 🛠️ Teknik Detaylar
* **Dil:** C#
* **Platform:** Windows Forms (.NET Framework)
* **Kullanılan Kontroller:** `RichTextBox`, `MenuStrip`, `SaveFileDialog`, `OpenFileDialog`, `FontDialog`.
* **Dosya Yönetimi:** `System.IO` kütüphanesi ile metin okuma ve yazma işlemleri.

## 🎮 Nasıl Kullanılır?
1. Uygulamayı başlatın.
2. Üst menüdeki "Dosya" (File) kısmından yeni bir belge açın veya kaydedin.
3. "Düzen" (Edit) menüsünden metin biçimlendirme işlemlerini yapın.
4. "Biçim" (Format) menüsünden yazı tipini kendinize göre özelleştirin.
